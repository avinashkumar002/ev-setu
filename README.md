# EvSetu – EV Charging Marketplace

Dual-role (Host / Driver) EV charging marketplace built with **Next.js 16 (App Router)** and **TypeScript**.

🔗 **Live Demo**: [https://charge-mate-tau.vercel.app](https://charge-mate-tau.vercel.app)

---

### Features
- Real-time charger discovery using **Leaflet maps**
- Multi-step booking & host onboarding flows
- Role-based dashboards (Host & Driver)
- Form handling with **React Hook Form + Zod** validation
- Image uploads via **ImageKit**
- Transactional emails with **Nodemailer**
- Client-side role-based access control + JWT auth sync
- Global state management with **Redux Toolkit + RTK Query**

### Tech Stack
- **Frontend**: Next.js 16, TypeScript, Tailwind CSS, Redux Toolkit
- **Forms & Validation**: React Hook Form, Zod
- **Maps**: Leaflet
- **Backend/DB**: Prisma, PostgreSQL (or your actual stack)
- **Auth**: JWT-based
- **Deployment**: Vercel
